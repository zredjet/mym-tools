# MyMyTools

個人用ローカルツールの集合体 — 保存系ツールと、変換・解析・生成・通信の開発ツール。

## v0.1.0-alpha.20 の主な変更

### 更新時の注意

- 初回起動時にデータベースを新しい形式 (schema v4) へ自動で更新します。更新前のデータは設定画面のバックアップ一覧に `pre-migration-v4-…` として自動保存されます

### 新機能

- PNG最適化を追加した (サイドバーの「その他」)。自作の shotq を内蔵し、`shotq --quality=70-85 --speed 11` と同じ結果で PNG を圧縮します。1 ファイルずつのほか、フォルダを指定して直下の PNG をまとめて処理でき、品質と速度も変えられます。品質が下限に届かない画像と小さくならない画像は元のまま残します
- Mermaid / ダイアグラム / ベクター描画のツールバーのボタンを、アイコンと短い名称の表記にそろえた

### データを守るための改善

- プロジェクト一覧の再読み込みに失敗しても、編集中の画面が閉じて入力が失われないようにした。上部に再試行ボタン付きのお知らせを表示します
- 未保存の確認で画面の移動をやめたとき、次回起動時に開く画面が移動先に書き換わっていた問題を修正
- 起動時にデータベースの版を読み取れなかった場合に、新しいデータベースと取り違えず、原因を起動停止画面に表示するようにした
- PDF 結合で、レイヤー (オプションコンテンツ) を含む PDF を拒否するようにした。結合で非表示のレイヤーが表示されてしまうのを防ぎます。文書の言語設定は引き継ぎます
- 保存時に作る一時ファイルが、長いファイル名で作れないことがあった問題を修正。上書き保存で既存ファイルのアクセス権を保つようにした

### 不具合の修正

- ベクター描画で、ダイアグラムから書き出した SVG を取り込めなかった問題を修正。HTML で描かれたラベルは通常の文字に置き換わり、太字などの書式は失われます
- HTTP で Shift_JIS / EUC-JP などの応答が文字化けしていた問題を修正。https から http へのリダイレクトは追従せず、遷移先を表示します
- ダイアログが重なっているときに Esc で全部閉じていた問題を修正。ダイアログを開いている間は、Tab でフォーカスが背後へ移らないようにした
- 処理を始めた直後のキャンセルが効かないことがあった問題を修正
- アプリの終了時などに、BinaryFormatter 解析 (NRBF) の補助プロセスが残ることがあった問題を修正
- プロジェクトを並び替えると、すべてのプロジェクトの更新日時が変わっていた問題を修正
- ダイアグラム / ベクター描画のエディタ用のローカルサーバーに、同時接続数の上限とタイムアウトを設けた

### 動作の軽量化

- 項目の多いプロジェクトを削除するときの処理を速くした
- 大きなファイルのハッシュ計算で、進捗の通知を減らした
- 一覧・検索・並び替えのデータベース処理を効率化した
- Mermaid / ダイアグラムの画像書き出しで、上限を超えるデータを読み込む前に拒否するようにした

## 含まれるportable ZIP

- **macOS**: `MyMyTools_*_macos_aarch64.zip` (Apple Silicon専用 / Intel Mac非対応)
- **Windows**: `MyMyTools_*_windows_x64.zip` (x64)

## インストール / 更新

1. このページのAssetsから自分のOSのZIPをダウンロード
2. **macOS**: ZIPを展開し、`MyMyTools.app`をApplicationsへ移動または既存版と差し替え
3. **Windows**: ZIP内の`MyMyTools.exe`と`nrbf-decoder.exe`を同じ任意フォルダへ展開し、`MyMyTools.exe`を起動または2ファイルとも既存版と差し替え

ユーザーデータはアプリ本体と別の場所に保存されるため、アプリを差し替えても維持されます。

## OS警告 / 起動エラー対処 (Phase 1はコード署名なし)

### Windows

SmartScreenの「不明な発行元」警告が表示された場合は、「詳細情報 > 実行」を選択してください。

### macOS

「MyMyToolsは壊れているため、起動できません」と表示される場合、ターミナルで以下を実行してquarantine属性を外します。

```bash
xattr -dr com.apple.quarantine /Applications/MyMyTools.app
```

実行後、通常どおり`MyMyTools.app`を起動してください。

## データの保存場所

- macOS: `~/Library/Application Support/com.zredjet.mymtools/`
- Windows: `%APPDATA%\com.zredjet.mymtools\`

バックアップは上記の`backups/`配下に保存されます。設定画面からリストアできます。

## 自動更新について

自動更新は提供しません。新版は同じReleasesページから手動でダウンロードし、アプリを差し替えてください。
