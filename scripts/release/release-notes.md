# MyMyTools

個人用ローカルツールの集合体 — 保存系ツールと、変換・解析・生成・通信の開発ツール。

## v0.1.0-alpha.24 の主な変更

「ベクター描画」を、自作のエディタ「キャンバス」に置き換えました。あわせて「JSON 整形」を追加し、アイテムを別のプロジェクトへ移動できるようにしました。データベースの形式は変わりませんが、ベクター描画の作品は新しい形式へ変換されます (下の「更新時の注意」を読んでください)。

### 追加・変更

- **キャンバス** (ベクター描画の置き換え。サイドバーの「カラー・デザイン」に並びます): UI モックやバナー、アイコンやロゴを作る Figma 風のエディタです
  - 無限キャンバスにフレーム・矩形・楕円・線・テキスト・画像・SVG を置き、選択・移動・リサイズ・整列・スナップ・スマートガイド・重なり順・Undo / Redo で編集します。レイヤーとプロパティのパネル、ルーラーとグリッドがあります
  - アイコン・ロゴ向けに、回転と左右・上下反転、ペンと点の編集、多角形・星・鉛筆、元の図形を残すブーリアン演算 (合体・型抜き・交差・中マド)、パスに変換、線のアウトライン化、線の端・角・破線を使えます
  - ブーリアン演算は、キャンバスの下のツールバーのボタン、右クリックのメニュー、ショートカット (Option + Shift + U / S / I / E) から行えます
  - 右クリックのメニューから、切り取り・コピー・貼り付け・複製・削除、グループ化、ブーリアン演算、重なり順、反転を行えます。レイヤーパネルの行でも開けます
  - PNG / JPEG / WebP の画像と SVG ファイルを取り込めます。フレーム・選択範囲・ページ全体を SVG と PNG (1〜3 倍) で書き出せます
  - 取り込んだ SVG は「埋め込み SVG」として置かれ、「編集できる形に変換」でグループ・パス・図形・テキストにできます。変換で失われるものがあるときは、変換の前に確認します
  - フォントは同梱せず、その PC のフォントを使います
- **JSON 整形** (サイドバーの「テキスト・解析」、最初から有効): JSON を検証し、整形・圧縮・キーの並べ替えを行います
  - 構文エラーは「3 行 20 文字目: 末尾のカンマは使えません」のように位置と理由を示し、入力欄の該当箇所へ移動できます
  - 数値や文字列は書かれたとおりに残します (`1.0` が `1` になる、大きな整数の桁が落ちる、といった変化を起こしません)。重複したキーは両方残して警告します
  - 入力は 1 MiB までです。コメント・末尾のカンマ (JSON5 / JSONC) と JSON Lines には対応しません
- **プロジェクト間の移動**: Prompt / Link / Memo / Color / Palette の一覧の各行の「別のプロジェクトへ移動」から、アイテムを別のプロジェクトへ移せます
- NRBF の解析に使う .NET を 10.0.14 に更新しました (ビルドに使う部品の脆弱性の修正)

### 更新時の注意

- ベクター描画で作った作品は、この版を最初に起動したときに、キャンバスの作品 (編集できない埋め込み SVG を 1 個置いたもの) へ変換されます。見た目は変わらず、そのまま書き出せます。編集したいときは、埋め込み SVG を選んで「編集できる形に変換」を使ってください
- この変換は戻せません。変換したキャンバスの作品は、以前の版のアプリでは開けません。変換の前に、起動時にバックアップ (`pre-payload-vector-v3`) を 1 回取ります。念のため、更新の前に今の版でバックアップか JSON エクスポートを取っておくことをおすすめします
- 変換できない作品は元の形式のまま残し、上書きの保存はしません。中身は画面の「元の SVG を書き出す」で取り出せます

### 既知の制限

- キャンバスでは、テキストのアウトライン化、コンポーネント、オートレイアウトにはまだ対応していません
- キャンバスで作った作品を別の PC で開くと、その PC にフォントがなければ、別のフォントで表示されます
- Mermaid / ダイアグラム / キャンバスのアイテムは、まだ別のプロジェクトへ移動できません
- ダイアグラムで、ページのタブをドラッグして並べ替えることはできません。タブの右クリックメニューの「移動」か、何も選択していない状態での Shift + ← / → で並べ替えてください

## 含まれるportable ZIP

- **macOS**: `MyMyTools_*_macos_aarch64.zip` (Apple Silicon専用 / Intel Mac非対応)
- **Windows**: `MyMyTools_*_windows_x64.zip` (x64)

## インストール / 更新

1. このページのAssetsから自分のOSのZIPをダウンロード
2. **macOS**: ZIPを展開し、`MyMyTools.app`をApplicationsへ移動または既存版と差し替え
3. **Windows**: ZIP内の`MyMyTools.exe`と`nrbf-decoder.exe`を同じ任意フォルダへ展開し、`MyMyTools.exe`を起動または2ファイルとも既存版と差し替え

ユーザーデータはアプリ本体と別の場所に保存されるため、アプリを差し替えても維持されます。

## OS警告 / 起動エラー対処 (Phase 1はコード署名なし)

### Windows

SmartScreenの「不明な発行元」警告が表示された場合は、「詳細情報 > 実行」を選択してください。

### macOS

「MyMyToolsは壊れているため、起動できません」と表示される場合、ターミナルで以下を実行してquarantine属性を外します。

```bash
xattr -dr com.apple.quarantine /Applications/MyMyTools.app
```

実行後、通常どおり`MyMyTools.app`を起動してください。

## データの保存場所

- macOS: `~/Library/Application Support/com.zredjet.mymtools/`
- Windows: `%APPDATA%\com.zredjet.mymtools\`

バックアップは上記の`backups/`配下に保存されます。設定画面からリストアできます。
