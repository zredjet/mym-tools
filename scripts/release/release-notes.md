# MyMyTools

個人用ローカルツールの集合体 — 保存系ツールと、変換・解析・生成・通信の開発ツール。

## v0.1.0-alpha.22 の主な変更

テキストを扱うツールを 4 つ追加し、アプリのアイコンを新しくしました。追加したツールはサイドバーの「テキスト・解析」に並び、最初から有効です (設定で無効にできます)。データベースの形式は変わりません。

### 追加

- **文字数カウント**: 文字数 (見た目の 1 文字単位)、空白・改行を除く文字数、行数・空行数、UTF-8 / Shift_JIS / UTF-16 のバイト数、全角・半角、文字種 (ひらがな・カタカナ・漢字など) を数えます
  - 選択した範囲だけの件数も並べて表示します
  - Shift_JIS で表せない文字 (絵文字や 〜 など) を一覧し、見えない文字も分かるようにします
- **テキスト整形**: 置換 → タブ → 行末の空白 → 空行 の順で整えます
  - 置換は文字列の一致で、ルールを複数並べられます。`\t` `\n` をタブ・改行として使うこともできます
  - タブは削除するか、2・4・8 個のスペースに置き換えます。対象をすべてか行頭だけかで選べます
  - 空行はすべて削除するか、続く空行を 1 行にまとめます
- **文字コード変換**: テキストファイルの文字コード (Shift_JIS / EUC-JP / UTF-8 / UTF-16 / ISO-2022-JP) を判定し、UTF-8 (BOM 付きも可) / Shift_JIS / EUC-JP と改行 (LF / CRLF) を選んで別名で保存します。元のファイルは変えません
  - 変換先で表せない文字や、読めないバイトがある時は保存せず、その位置 (行・文字) を表示します
  - Mac で入力した 〜 や — などを、Windows で使われる形 (～ や ―) に寄せるオプションがあります
- **CSV ビューア**: CSV / TSV を貼り付けるか、ファイルから読み込んで表で表示し、JSON・Markdown の表・CSV・TSV に変換してコピーできます
  - Excel で保存した Shift_JIS の CSV や、Excel からコピーしたセル (セル内の改行を含む) もそのまま読めます
  - 表に出すのは先頭 1,000 行までです。変換結果には全体が入ります

### 変更

- アプリのアイコンを新しくした

### 不具合の修正

- ⌘K の検索で、絞り込みボタンの文字が 2 行に折れて表示されていた問題を修正

### 既知の制限

- ダイアグラムで、ページのタブをドラッグして並べ替えることはできません。タブの右クリックメニューの「移動」か、何も選択していない状態での Shift + ← / → で並べ替えてください

## 含まれるportable ZIP

- **macOS**: `MyMyTools_*_macos_aarch64.zip` (Apple Silicon専用 / Intel Mac非対応)
- **Windows**: `MyMyTools_*_windows_x64.zip` (x64)

## インストール / 更新

1. このページのAssetsから自分のOSのZIPをダウンロード
2. **macOS**: ZIPを展開し、`MyMyTools.app`をApplicationsへ移動または既存版と差し替え
3. **Windows**: ZIP内の`MyMyTools.exe`と`nrbf-decoder.exe`を同じ任意フォルダへ展開し、`MyMyTools.exe`を起動または2ファイルとも既存版と差し替え

ユーザーデータはアプリ本体と別の場所に保存されるため、アプリを差し替えても維持されます。

## OS警告 / 起動エラー対処 (Phase 1はコード署名なし)

### Windows

SmartScreenの「不明な発行元」警告が表示された場合は、「詳細情報 > 実行」を選択してください。

### macOS

「MyMyToolsは壊れているため、起動できません」と表示される場合、ターミナルで以下を実行してquarantine属性を外します。

```bash
xattr -dr com.apple.quarantine /Applications/MyMyTools.app
```

実行後、通常どおり`MyMyTools.app`を起動してください。

## データの保存場所

- macOS: `~/Library/Application Support/com.zredjet.mymtools/`
- Windows: `%APPDATA%\com.zredjet.mymtools\`

バックアップは上記の`backups/`配下に保存されます。設定画面からリストアできます。
