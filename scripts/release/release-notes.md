# MyMyTools

個人用ローカルツールの集合体 — 保存系ツールと、変換・解析・生成・通信の開発ツール。

## v0.1.0-alpha.19 の主な変更

### 更新時の注意

- 初回起動時にデータベースを新しい形式 (schema v3) へ自動で更新します。更新前のデータは設定画面のバックアップ一覧に `pre-migration-v3-…` として自動保存されます

### 新機能

- サイドバー全体を開閉できるようにした。トップバー左端のボタン、または `Cmd/Ctrl + B` (`Cmd/Ctrl + \` でも可) で閉じてメイン画面を広く使えます。状態は次回起動時も維持されます

### データを守るための改善

- プロジェクトを削除する前に、自動でバックアップ (`pre-delete-project-…`) を取るようにした
- 未保存の編集がある状態でウィンドウを閉じる / `Cmd+Q` で終了しようとすると、確認を表示するようにした (Mermaid / ダイアグラム / パレット / メモ。ベクター描画は従来どおり)
- インポートしたリンクのネットワーク共有パス (`\\server\share` など) は開かないようにし、アプリやスクリプトなど実行されるファイルは開く前に確認するようにした
- 古いバージョンで取ったバックアップからもリストアできるようにした。新しいバージョンで作られたバックアップはリストア前に拒否します
- 本文が空白だけの古いメモがあると、アプリが起動できなくなる可能性があった問題を修正

### 不具合の修正

- 横断検索で `#ff0000` や `https://…`、`-` や `"` を含む語を検索するとエラーになっていた問題を修正。空白区切りの複数語は、すべてを含むものを表示します
- プロンプト / カラーの一覧が 100 件までしか表示されず、それを超えると並び替えに失敗していた問題を修正
- 正規表現 / テキスト差分の計算が配布版で動かない可能性があった問題を修正
- Mermaid / ダイアグラムで、新規作成の直後に保存すると同じ図がもう一度作られることがあった問題を修正
- ハッシュ計算で、小さなファイルを落とすと「計算中」のまま止まることがあった問題を修正
- JSON インポートで追加されたプロジェクトが、再起動するまでサイドバーに表示されなかった問題を修正
- About 画面の「ユーザーデータフォルダを開く」が動かなかった問題を修正
- 画面の表示中にエラーが起きても、サイドバーが残り別の画面へ移れるようにした

### 動作の軽量化

- 大きなベクター描画の保存、エクスポート / インポート、バックアップ / リストアの間に画面が固まりにくくなった
- 項目の多いプロジェクトでも並び替えが遅くならないようにした
- 起動時に読み込む量を約半分に減らし、Mermaid / ダイアグラムの文書一覧で本文を読み込まないようにした
- BinaryFormatter 解析 (NRBF) で、大きなツリーを検索するときの入力の引っかかりを減らした

## 含まれるportable ZIP

- **macOS**: `MyMyTools_*_macos_aarch64.zip` (Apple Silicon専用 / Intel Mac非対応)
- **Windows**: `MyMyTools_*_windows_x64.zip` (x64)

## インストール / 更新

1. このページのAssetsから自分のOSのZIPをダウンロード
2. **macOS**: ZIPを展開し、`MyMyTools.app`をApplicationsへ移動または既存版と差し替え
3. **Windows**: ZIP内の`MyMyTools.exe`と`nrbf-decoder.exe`を同じ任意フォルダへ展開し、`MyMyTools.exe`を起動または2ファイルとも既存版と差し替え

ユーザーデータはアプリ本体と別の場所に保存されるため、アプリを差し替えても維持されます。

## OS警告 / 起動エラー対処 (Phase 1はコード署名なし)

### Windows

SmartScreenの「不明な発行元」警告が表示された場合は、「詳細情報 > 実行」を選択してください。

### macOS

「MyMyToolsは壊れているため、起動できません」と表示される場合、ターミナルで以下を実行してquarantine属性を外します。

```bash
xattr -dr com.apple.quarantine /Applications/MyMyTools.app
```

実行後、通常どおり`MyMyTools.app`を起動してください。

## データの保存場所

- macOS: `~/Library/Application Support/com.zredjet.mymtools/`
- Windows: `%APPDATA%\com.zredjet.mymtools\`

バックアップは上記の`backups/`配下に保存されます。設定画面からリストアできます。

## 自動更新について

自動更新は提供しません。新版は同じReleasesページから手動でダウンロードし、アプリを差し替えてください。
